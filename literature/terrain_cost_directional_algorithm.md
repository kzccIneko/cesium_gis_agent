# DEM方向性地形通行代价分析算法说明

## 1. 问题定义

给定 DEM 栅格与两点 `S(起点)`、`T(终点)`，在由两点对角框扩展得到的分析域内，计算每个栅格单元的**方向性最小通行代价**。  
输出既包含代价值，也包含该最小代价对应的坡向（方位角）与方向坡度，供前端渲染与数值提示使用。

目标是构建**由地形机理驱动**、不依赖车辆主观参数的代价模型。

---

## 2. 地形要素与客观量化

### 2.1 一阶地形导数（坡度/坡向）

对 DEM 使用 3×3 邻域中心差分（Horn 类方法）估计：

- `f_x = ∂z/∂x`
- `f_y = ∂z/∂y`

则：

- 坡度（弧度）`θ = atan(sqrt(f_x^2 + f_y^2))`
- 坡度（度）`slope_deg = θ * 180/π`
- 坡向（度）`aspect_deg = atan2(f_y, -f_x)` 的地理方位归一化

这对应 GIS 常用坡度/坡向定义（ArcGIS/GRASS/RichDEM 一致体系）。

### 2.2 二阶地形导数（曲率）

利用 3×3 离散二阶差分估计：

- `f_xx, f_yy, f_xy`
- 曲率强度 `curvature = sqrt(f_xx^2 + f_yy^2 + 2*f_xy^2)`

曲率反映地形弯曲程度，弯曲强通常对应路径局部不平顺度增加。

### 2.3 山脊/谷线强度（流线代理）

由高程梯度场构造“线性地形组织”强度：

- `flowline_intensity = ||∇z||` 的归一化表达（实现中由梯度及邻域派生）

用于客观表达脊谷结构对通行难度的放大效应。

---

## 3. 方向性代价函数构建

### 3.1 候选方向集合

对每个栅格中心，取 8 个离散方向：

`D = {0°,45°,90°,135°,180°,225°,270°,315°}`

对应水平步长：

- 轴向步长 `Δs_cardinal = cell_size_m`
- 对角步长 `Δs_diag = sqrt(2)*cell_size_m`

### 3.2 方向坡度与地表几何长度因子

方向单位向量 `u=(cosα,sinα)`，则方向高程梯度：

`g_α = f_x*cosα + f_y*sinα`

地表长度放大系数（单位水平位移对应真实地表路径增益）：

`L_α = sqrt(1 + g_α^2)`

### 3.3 地形惩罚项（无量纲）

对曲率与线性地形强度做归一化（百分位稳健归一化），构造惩罚：

- `P_curv = 1 + norm(curvature)`
- `P_flow = 1 + norm(flowline_intensity)`
- `P = P_curv * P_flow`

### 3.4 单方向候选代价

`C_α = Δs_α * L_α * P`

其中 `Δs_α` 为轴向/对角步长。

### 3.5 起终点驱动的方向约束（核心）

对当前栅格中心 `x`，定义“朝向终点”的单位向量：

`g(x) = (T - x) / ||T - x||`

仅保留满足：

`u_α · g(x) > 0`

的方向（即方向必须位于“朝向终点半平面”），实现方向性约束。  
若某点因数值退化无可用方向，则退回全方向最小代价兜底。

### 3.6 栅格输出

对每个栅格取：

- `cost(x) = min_{α∈D, u_α·g(x)>0} C_α`
- `min_cost_dir_deg(x) = argmin` 对应方位角
- `min_cost_dir_slope_deg(x) = atan(|g_α*|)`（最优方向坡度）

---

## 4. 工程化可行性与分辨率影响

1. **分辨率影响**  
   栅格尺度越细，`f_x,f_y,f_xx,f_yy,f_xy` 对噪声越敏感；尺度越粗，微地形被平滑。  
   本实现通过统一网格分辨率计算并在前端提示“实际米/格”。

2. **方向离散误差**  
   8 方向是工程效率与方向精度折中；可扩展到 16/32 方向，但计算量线性增大。

3. **经纬度到米换算**  
   在局部纬度下使用 `lon->m` 与 `lat->m` 换算，保证方向向量与步长具备物理量纲一致性。

4. **缓存一致性**  
   方向性结果依赖 `S/T`，因此缓存键必须包含 `start_point/end_point`，避免复用到错误方向场。

---

## 5. 前后端流程（当前实现）

1. 用户点击后端“代价分析”，先在地图点选两点（点外提示重选）。  
2. 两点用于：  
   - 形成分析 BBox（可外扩）  
   - 写入 `start_point/end_point` 作为方向约束输入
3. 后端按分析域栅格计算 `cost/min_cost_dir_deg/min_cost_dir_slope_deg`。  
4. 导出 GeoJSON 时附带上述字段。  
5. 前端数值提示显示：代价、坡度、最小代价坡向、对应方向坡度。

---

## 6. 与路径规划衔接

该方向性代价场可直接作为路径搜索（Dijkstra/A*）的栅格边权基础：  
边权可取目标栅格 `cost` 或两端均值；若保留方向边权，可进一步升级为有向图代价搜索。
