# DEM方向性通行代价模型实验结果报告

## 1. 实验目的

1. 验证一/二阶地形导数估计的数值正确性。
2. 验证多要素代价模型（坡度+曲率+脊谷+等高线密度+方向约束）相对基线的优势。
3. 验证多分辨率下模型稳定性。
4. 验证起终点方向性约束带来的各向异性效果。

## 2. 导数精度验证（合成地形）

- 平均梯度RMSE: **0.283879**
- 平均二阶项RMSE(拉普拉斯): **0.310857**

## 5. 结果解释

1. **导数误差验证**：若梯度/二阶项误差低，说明后续代价项构造具有数值基础。
2. **消融优势**：若 OURS 在总代价、曲折率、单位长度爬升上整体更优，表明综合建模优于单因素建模。
3. **方向性检验**：起终点互换后路径重合度下降、分布差异显著，说明模型确实是各向异性。
4. **多尺度稳定性**：跨尺度路径Hausdorff距离与指标CV可反映工程可迁移性。
