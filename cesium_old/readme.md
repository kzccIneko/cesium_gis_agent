## 项目名称
> Cesium地理信息可视化系统_调试版


## 新增功能
2025/10/28 
增加非结构化地图路径规划功能，路径通行能力代价基于论文给的坡度或转向映射出的代价值和权重值计算

2025/11/5
新增原始映射方法的反向搜索计算代价值作为正向搜索的启发函数代价值

2025/11/10
新增水域与可通行区域划定

2025/11/21 
新增基于运动学公式和坡度、转向因素计算等效时间作为寻路代价的方法（v01）
新增全路径陡峭度和陡峭度变化分析功能

组会提出的问题: 1.没设置牵引力，牵引力能更好反映通行能力？而不是设定初始速度。固定好牵引力为最大牵引力。
               2.牵引力、坡度、转向、路程结合算速度，速度放在全局根据运动学公式累积计算（比如坡度大的地方即使牵引力不足，速度够也能过，下坡不限速）
