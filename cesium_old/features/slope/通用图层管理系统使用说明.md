# 通用图层管理系统 - 使用说明（已完成）

## ✅ 概述

已实现的通用图层管理系统可以**自动管理和操作**项目中的所有 Primitive 和 Entity 图层。

## 🎯 核心功能

### 1. 自动注册 ✅

系统会在创建 primitive/entity 时**自动注册**到图层管理系统，无需手动操作。

#### 已自动注册的图层：

| 图层 ID | 图层名称 | 类型 | 注册时机 |
|---------|----------|------|----------|
| `slope` | 坡度图层 | primitive | `createPolygonInstance(config=0)` 时 |
| `aspect` | 坡向图层 | primitive | `createPolygonInstance(config=1)` 时 |
| `cost` | 代价图层 | primitive | `createCostInstance()` 时 |
| `pathLines` | 路径线 | entity | A* 路径规划完成后 |
| `roadOverride` | 道路覆盖 | entity | 绘制道路覆盖区完成后 |
| `waterOverride` | 水域覆盖 | entity | 绘制水域覆盖区完成后 |

### 2. 图层置顶 ✅

#### 操作步骤：

1. 点击 **"刷新图层列表"** 按钮
2. 在下拉框中选择要置顶的图层
3. 点击 **"置顶"** 按钮

#### 技术原理：

- **Primitive 类型**：使用 Cesium 原生 `viewer.scene.primitives.raiseToTop()` 方法
- **Entity 类型**：通过 `entities.remove()` + `entities.add()` 实现置顶效果

```javascript
// Primitive 置顶（Cesium 原生方法）
primitives.raiseToTop(item.primitive);

// Entity 置顶（删除再添加到末尾）
entities.remove(entity);
entities.add(entity);
```

### 3. 图层可见性管理 ✅

通过原有的图层可见性开关控制：

- ✅ 坡度图层可见性开关
- ✅ 坡向图层可见性开关
- ⚠️ 代价图层暂无独立开关（使用坡度开关）

## 📖 API 说明

### registerLayer(layerId, layerName, type, items)

注册或更新图层到管理系统。

**参数：**
- `layerId` (string) - 图层唯一标识，如 `'slope'`, `'aspect'`, `'cost'`, `'pathLines'`
- `layerName` (string) - 图层显示名称，如 `'坡度图层'`, `'路径线'`
- `type` (string) - 图层类型，`'primitive'` 或 `'entity'`
- `items` (Array|Object) - 图层内容数组或对象

**返回值：** boolean - 注册成功返回 `true`

**示例：**
```javascript
// 注册 primitive 图层（在 createPolygonInstance 中自动调用）
this.registerLayer('slope', '坡度图层', 'primitive', this.slopePolygons);

// 注册 entity 图层（在路径规划完成后自动调用）
this.registerLayer('pathLines', '路径线', 'entity', this.pathLines.map(p => p.pathLineEntity));
```

## 🛠️ 添加自定义图层

如果需要添加新的自定义 primitive/entity，只需在创建后立即调用 `registerLayer()`：

```javascript
// ========== 示例 1: 添加自定义 primitive ==========
const customPrimitive = viewer.scene.primitives.add(new Cesium.Primitive({
  geometryInstances: new Cesium.GeometryInstance({
    geometry: new Cesium.RectangleGeometry({
      rectangle: Cesium.Rectangle.fromDegrees(-100.0, 30.0, -90.0, 40.0),
      height: 100000.0
    }),
    id: 'customRect',
    attributes: {
      color: Cesium.ColorGeometryInstanceAttribute.fromColor(Cesium.Color.RED)
    }
  }),
  appearance: new Cesium.PerInstanceColorAppearance()
}));

this.customPrimitives = this.customPrimitives || [];
this.customPrimitives.push({primitive: customPrimitive, name: 'Custom1'});

// 🔑 关键：立即注册到图层管理系统
this.registerLayer('customLayer', '自定义 Primitive 图层', 'primitive', this.customPrimitives);


// ========== 示例 2: 添加自定义 entity ==========
const customEntity = viewer.entities.add({
  id: 'customPoint',
  position: Cesium.Cartesian3.fromDegrees(-75.59777, 40.03883),
  point: {
    pixelSize: 10,
    color: Cesium.Color.YELLOW
  }
});

this.customEntities = this.customEntities || [];
this.customEntities.push(customEntity);

// 🔑 关键：立即注册到图层管理系统
this.registerLayer('customEntityLayer', '自定义 Entity 图层', 'entity', this.customEntities);
```

### 置顶原理详解

#### ✅ Primitive 置顶

Cesium 的 `PrimitiveCollection` 提供了 `raiseToTop(primitive)` 方法，可以将指定 primitive 移动到渲染队列的**末尾**（最顶层）。

```javascript
const primitives = viewer.scene.primitives;
primitives.raiseToTop(primitive); // 将 primitive 提升到最顶层
```

**优点：** 
- Cesium 原生方法，性能好
- 不会触发重新渲染
- 无闪烁问题

#### ✅ Entity 置顶

Cesium 的 `EntityCollection` **没有**提供直接的置顶方法，但可以通过以下方式实现：

1. 将 entity 从 `viewer.entities` 中移除
2. 重新添加到 `viewer.entities`（添加到末尾 = 最顶层）

```javascript
const entities = viewer.entities;
entities.remove(entity);
entities.add(entity); // 重新添加到最后（最顶层）
```

**缺点：**
- ⚠️ 会触发 entity 的重新渲染，可能会有短暂的闪烁

**替代方案：**
- 使用 `heightReference` 属性调整相对高度
- 使用 `zIndex` 属性（部分 entity 支持）
- 使用 DataSource 分组管理（更复杂但更灵活，参考 CSDN 博客）

## ❓ 常见问题

### Q1: 为什么点击置顶后看不到效果？

**可能原因：**
1. ❌ **图层为空**（count = 0）- 请先绘制该类型的图层
2. ❌ **其他图层遮挡** - 尝试将其他图层隐藏或降低透明度
3. ❌ **多个图层重叠且颜色相近** - 调整颜色或透明度以便区分

**解决方案：**
```javascript
// 1. 检查图层是否为空
console.log(window.SlopeAnalysis.getAvailablePrimitives());

// 2. 隐藏其他图层
document.getElementById('slopeLayerVisibility').click(); // 隐藏坡度图层

// 3. 调整透明度
window.SlopeAnalysis.setSlopePolygonsAlpha(0.3); // 降低坡度图层透明度
```

---

### Q2: Entity 置顶会闪烁怎么办？

**原因：** Entity 置顶通过删除再添加实现，这是 Cesium 的限制。

**解决方案：**

**方案 1：使用 heightReference 调整高度**
```javascript
entity.polygon.heightReference = Cesium.HeightReference.RELATIVE_TO_GROUND;
entity.polygon.height = 100; // 提高 100 米
```

**方案 2：使用 DataSource 分组管理（推荐）**
```javascript
// 创建专用 DataSource
const pathDataSource = new Cesium.CustomDataSource('pathLines');
viewer.dataSources.add(pathDataSource);

// 将 entity 添加到 DataSource
pathDataSource.entities.add(pathLineEntity);

// 置顶整个 DataSource（无闪烁）
viewer.dataSources.raiseToTop(pathDataSource);
```

参考：[CSDN 博客 - Cesium Entity 高亮显示](https://blog.csdn.net/qq_38370387/article/details/119817934)

---

### Q3: 如何添加更多自定义图层？

**步骤：**

1. 创建 primitive/entity
2. 将其添加到数组
3. 立即调用 `registerLayer()`

```javascript
// ========== 在你的代码中 ==========
// 1. 创建 primitive
const myPrimitive = viewer.scene.primitives.add(...);

// 2. 添加到数组
this.myCustomArray = this.myCustomArray || [];

// 3. 🔑 关键：立即注册
this.registerLayer('myCustomId', '我的自定义图层', 'primitive', this.myCustomArray);
```

### Q5: 路径线置顶后为什么还被坡度图层遮挡？

**原因：** Entity 和 Primitive 的渲染顺序不同：
- Primitive 通过 `scene.primitives` 渲染（先渲染）
- Entity 通过 `viewer.entities` 渲染（后渲染，理论上在 primitive 之上）

**解决方案：**

**方案 1：降低 primitive 图层透明度**
```javascript
window.SlopeAnalysis.setSlopePolygonsAlpha(0.3); // 坡度图层半透明
```

**方案 2：将路径线转换为 Primitive**
```javascript
// 使用 GroundPolylinePrimitive 代替 Entity.polyline
const pathPrimitive = viewer.scene.groundPrimitives.add(new Cesium.GroundPolylinePrimitive({
  geometryInstances: new Cesium.GeometryInstance({
    geometry: new Cesium.GroundPolylineGeometry({
      positions: pathPoints,
      width: 5.0
    }),
    attributes: {
      color: Cesium.ColorGeometryInstanceAttribute.fromColor(Cesium.Color.RED)
    }
  }),
  appearance: new Cesium.PolylineColorAppearance()
}));
```

```javascript
// ========== 在 SlopeAspect.prototype 中添加自定义方法 ==========
SlopeAspect.prototype.addCustomMarker = function(lon, lat, label) {
  const viewer = this.viewer;
  
  // 1. 创建 entity
  const marker = viewer.entities.add({
    position: Cesium.Cartesian3.fromDegrees(lon, lat),
    billboard: {
      image: 'path/to/marker.png',
      scale: 0.5
    },
    label: {
      text: label,
      font: '14pt sans-serif',
      fillColor: Cesium.Color.WHITE,
      outlineColor: Cesium.Color.BLACK,
      outlineWidth: 2,
      style: Cesium.LabelStyle.FILL_AND_OUTLINE
    }
  });
  
  // 2. 添加到数组
  this.customMarkers = this.customMarkers || [];
  this.customMarkers.push(marker);
  
  // 3. 🔑 立即注册到图层管理系统
  this.registerLayer('customMarkers', '自定义标记', 'entity', this.customMarkers);
  
  return marker;
};

// ========== 使用 ==========
```
